### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/Abhay17pawar/faktura_frontend.git
   ```
2. cd faktura_frontend
3. Install NPM packages
   ```sh
   npm install
   ```
4. 
   ```sh
   npm run dev
   ```
